# Saint Website

Static website for the Saint Discord application.

Files:
- index.html — main landing page
- terms.html — Terms of Service
- privacy.html — Privacy Policy
- styles.css — shared styling
- script.js — Discord invite placeholder

Before production:
1. Replace INVITE_URL in script.js with Saint's real Discord installation URL.
2. Replace the support email placeholder in index.html.
3. Review Terms and Privacy so they exactly match Saint's actual data collection, storage, hosting, and features.
4. Deploy the folder to a public HTTPS host such as GitHub Pages.
